# Architecture

## Overview

HIMAL is a single Flutter codebase targeting Windows, Linux, macOS, iOS and Android.
Playback is delegated to [media_kit](https://github.com/media-kit/media-kit), which
wraps libmpv + FFmpeg, giving universal format/codec/HDR support.

## Layers

```
lib/
├── main.dart              # entry point, engine init
├── app.dart               # MaterialApp + providers
├── core/
│   ├── constants/         # app constants, colors
│   ├── theme/             # light/dark themes
│   ├── utils/             # helpers
│   └── services/          # platform services
├── features/
│   ├── player/            # player screen + controller
│   ├── settings/          # settings screen + controller
│   ├── library/           # (planned) media library
│   ├── playlist/          # (planned) playlist management
│   └── onboarding/        # (planned)
├── screens/               # top-level screens (home)
└── widgets/               # shared widgets
```

## State management

`provider` with `ChangeNotifier`. Two main controllers:
- `SettingsController` — persisted preferences (SharedPreferences).
- `PlayerController` — playback state, playlist, recent/favorites.

## Playback

`PlayerController` owns a `media_kit` `Player` and `VideoController`. It exposes
a reactive API (play, pause, seek, volume, speed, tracks) and listens to streams
for position/duration/status updates.

## Platform specifics

- Desktop windowing via `window_manager`.
- Mobile keeps screen on via `wakelock_plus` when enabled.
- Platform scaffolding generated by `flutter create` (see CI).

## Data flow

UI widgets `watch` controllers via `context.watch<T>()` and call methods.
Controllers notify listeners; UI rebuilds. No global mutable state outside
controllers.
